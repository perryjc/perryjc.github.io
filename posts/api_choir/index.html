Bird Scooter Chaos Script

November 4, 2026

API Choir Project

                  In this project, I was orignaly tasked with creating a Jupyter Notebook, that would make
                  at least one API call, then create a visualization of the data as well as additional analysis.
                  I was able to finsh this task in about 15 minutes. I didnt want to be lazy so I continued working.
                  I moved from a notebook to a Python script and insted of GET requests I started to play with
                  POST and PUT requests. In my personal life,I also was working on a bug bounty for Bird scooters
                  and that made me focus on unintended useage of the API. 
                
                  My script works by first prompting the user for a loation, then it will make a POST request to the
                  first endpoint and it will return a list of nearby scooters. then it will make a dictionary of 
                  the scooter IDs, as well as their lat and long. then the dictionary will be sorted by how far
                  the scooters are from the inputted location. then the sorted dictionary will be put into a for
                  loop and will make a PUT request to the second endpoint (Chirp) with the scooter ID as the payload.
                  additionally the payload json object has a boolean key called "alarm" which is set to False by 
                  default, but can be set to True without any authentication. Finally all Bird brand scooters around
                  the location entered by the user will make a loud alarm sound at the same time.
